# Home Decor - Интернет-магазин комнатных растений

## О проекте

Home Decor - полнофункциональное веб-приложение интернет-магазина комнатных растений и товаров для домашнего озеленения. Приложение позволяет просматривать каталог продукции, изучать характеристики растений, добавлять товары в избранное и корзину, а также оформлять и отслеживать заказы.

Проект реализован с использованием Angular и Node.js. Клиентская часть взаимодействует с собственным REST API, а для хранения информации о пользователях, товарах, корзинах и заказах используется MongoDB.

## Функциональность

- **Каталог товаров:** просмотр ассортимента растений с фотографиями, описаниями, ценами и характеристиками.
- **Поиск товаров:** поиск продукции по названию.
- **Фильтрация и сортировка:** отбор товаров по категориям, типам растений, высоте и диаметру, сортировка по названию и стоимости.
- **Карточка товара:** просмотр подробной информации о растении, включая условия освещения, влажности и температуры.
- **Корзина:** добавление товаров, изменение их количества, удаление позиций и автоматический пересчёт общей стоимости.
- **Избранное:** добавление и удаление понравившихся товаров из списка избранного.
- **Регистрация и авторизация:** создание аккаунта и вход в систему с использованием электронной почты и пароля.
- **Личный кабинет:** просмотр и редактирование пользовательской информации.
- **Оформление заказов:** создание заказов на основе выбранных товаров и данных пользователя.
- **История заказов:** просмотр ранее оформленных заказов в личном кабинете.
- **Главная страница:** карусель популярных товаров, отзывы покупателей, информация о доставке и способах оплаты.

## Особенности реализации

**Frontend:**
- Компонентная архитектура с разделением приложения на функциональные и общие модули.
- Использование Angular Router и ленивой загрузки модулей для организации маршрутизации.
- Создание сервисов для взаимодействия с API и управления данными товаров, корзины, избранного и пользователей.
- Использование RxJS и Observable для обработки асинхронных операций.
- Реализация HTTP-интерцептора для автоматического добавления токена авторизации и обновления токенов при истечении срока действия.
- Защита маршрутов личного кабинета с помощью Guards.
- Использование реактивных форм и встроенных валидаторов Angular.

**Backend:**
- Разработка REST API на Express.js.
- Организация серверной логики с использованием контроллеров, моделей и сервисов.
- Работа с MongoDB через Mongoose.
- Реализация регистрации и авторизации с использованием JWT и refresh-токенов.
- Хеширование пользовательских паролей с помощью bcryptjs.
- Валидация входящих данных на стороне сервера.

## Запуск проекта

Для локального запуска потребуются:
- Node.js и npm.
- Установленная и запущенная MongoDB.

### 1. Клонирование репозитория

```bash
git clone https://github.com/Kryanrd/IM-Angular.git
cd IM-Angular
```

### 2. Настройка базы данных

Установите и запустите MongoDB.

По умолчанию backend использует локальное подключение:

`mongodb://127.0.0.1:27017`

Название базы данных:

`im`

Перед запуском приложения необходимо подготовить базу данных и наполнить её необходимыми данными о категориях, типах растений и товарах.

### 3. Запуск Backend

Откройте первый терминал и перейдите в папку `backend`:

```bash
cd backend
```

Установите зависимости:

```bash
npm install
```

Запустите сервер:

```bash
npm start
```

Backend будет доступен по адресу:

`http://localhost:3000`

### 4. Запуск Frontend

Откройте второй терминал в корневой папке проекта и перейдите в `frontend`:

```bash
cd frontend
```

Установите зависимости:

```bash
npm install
```

Запустите приложение:

```bash
npm start
```

Frontend будет доступен по адресу:

`http://localhost:4200`

Для корректной работы приложения необходимо одновременно запустить MongoDB, Backend и Frontend.

## Сборка проекта

Для создания production-сборки frontend выполните команду из папки `frontend`:

```bash
npm run build
```

Собранные файлы приложения будут размещены в папке `dist/frontend/`.
